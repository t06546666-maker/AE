# Version 70 (1.0.69) — merchant-away checkout mode

This corrects the interpretation of activation: the merchant selects who handles new checkout requests for the shop, rather than making a new staff account inactive by default. Creating staff grants sign-in access; the existing Enable/Disable account control remains separate. In the Counter Staff menu, “I am away — activate Counter Staff” turns on delegated checkout; “I am back — switch to Merchant” returns checkout to the owner. No automatic location/presence detection is used.

New checkout request and correction pushes go exclusively to active, password-ready staff while the mode is on. With the mode off, the merchant receives checkout alerts, staff checkout queues are hidden and staff confirmation is blocked. Merchant foreground alerts exclude delegated checkout requests while staff mode is active. Existing pending delegated requests reappear in the merchant queue after switching back. Point/discount rules are preserved by the dedicated mode update. Product-list and transaction-completion notifications remain as previously requested.
